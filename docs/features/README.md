# Features

Larger, user-facing capabilities of modelWrecker. Each feature doc explains what it is for, how it works,
and its security notes, with a small diagram. Add a doc here when a major feature lands, and a row to
[`../DOCUMENTATION.md`](../DOCUMENTATION.md).

| Feature | What it gives the user | Status | Doc |
|---------|------------------------|--------|-----|
| Harness integration | Drive modelWrecker from Claude Code / Codex / any MCP client and get findings back | Planned (Phase 9) | [harness-integration.md](harness-integration.md) |

More features (campaigns, the payload engine, the judge ensemble) are documented under their own areas;
this folder is for cross-cutting, user-facing capabilities that do not belong to a single engine part.
